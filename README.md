## Estrutura

```
kaiky-concept/
├── index.html   # site completo (HTML, CSS e JS em um único arquivo)
├── img/         # banner e capas dos projetos
└── README.md
```

## Como editar

- **Textos, contato e links:** edite direto no `index.html`.
- **Projetos:** a lista fica no `<script>` no fim do `index.html` (constante `projects`) — título, categoria, imagem e link do Behance.
- **Imagens:** coloque o arquivo na pasta `img/` e use o mesmo nome na lista de projetos.

Depois de salvar no GitHub, o site atualiza sozinho em 1–2 minutos (GitHub Pages, branch `main`, pasta raiz).
